# Phantombite_Sulvax

Planeten-Mod der Phantombite Mod Suite für Space Engineers: der Planet **Sulvax** (Planetendefinition, Planetendaten,
Voxelkarten und Texturen). Reiner Daten-Mod, kein Skript.

Zum Spawnen an einer festen Position in der Welt dient `Phantombite_PlanetSpawner`.
Passender Begleitmod: `Phantombite_Sulvax_RespawnRover` (Respawn-Fahrzeug für diesen Planeten).
